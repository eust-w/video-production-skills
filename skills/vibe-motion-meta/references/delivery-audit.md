# 需要分享或去品牌时检查交付包

仅在用户要求去品牌、对外分享、打包或明确检查残留时执行。检查对象是这次实际交付的文件与包，不将结论扩大到未检查的历史目录。

## 先确定范围

从用户要求提取需删除或替换的名称、别名、旧 Logo、渠道、域名、内部路径与人物信息。不要内置某家公司或本次案例的词表。保留合法来源、第三方许可证与 AI 内容凭证；去品牌不意味着抹除来源。

若必须保留的第三方署名含有用户要求删除的标识，优先替换相关依赖／素材；无法替换时说明具体冲突与剩余限制，不能删去必要署名，也不能声称已经满足零残留要求。

核对渲染文本与真实画面、音轨，再检查源码、未用但随包发送的函数、文件名、素材、图像提示词、文档、运行配置、媒体元数据和压缩包条目。更名后重新测宽、居中，并核对转场目标。实际看过成片且正确替换后，再导出并用最新文件重新打包。

公开复现提示词若经过删除旧标识或改写，应标明“经整理的复现提示词”，不能伪装成原始生成记录；原始记录留在非交付工作区。检查元数据时使用适合媒体的工具，不能仅靠源码搜索。

## 可选只读关键词工具

随包的 [audit_delivery.py](../scripts/audit_delivery.py) 使用 Python 3 标准库，无网络与第三方依赖。针对目录或一个 ZIP 检查文件名和可读取字节，支持 UTF-8、UTF-16LE／BE 与大小写折叠；ZIP 在内存流中读取，不解压到磁盘。不删除、改写或清洗原文件，只有指定 `--report` 时写报告。

以下路径均为示例，应替换成当前项目路径与用户指定词表：

```bash
python3 scripts/audit_delivery.py /path/to/delivery --term '旧产品名' --term 'old-brand'
python3 scripts/audit_delivery.py /path/to/delivery.zip --terms-file /path/to/terms.txt --report /path/to/audit.json
```

脚本路径相对于本 Skill 根目录。`--terms-file` 使用 UTF-8，每个非空行一个字面关键词。报告只列相对路径、命中词及检查状态，不摘录可能敏感的正文；报告本身可能包含旧名称，分享时另行判断是否应纳入。

- 退出码 `0`：扫描完成，所给词表无命中。
- 退出码 `1`：扫描完成，有命中，需要人工判断。
- 退出码 `2`：检查不完整或发生错误，优先于命中状态；查看 `skipped`／`errors`。

默认单文件上限 128 MiB、总读取及输入 ZIP 大小上限 512 MiB、目录／压缩包条目数上限 10000；必要时显式调整。软链接、嵌套或不支持的压缩包、不安全的 ZIP 路径、加密条目和超限内容会记录为未检查，不能宣称全部通过。

它不识别图片 Logo、OCR、音频中的名字，也不解码任意嵌入数据或压缩媒体元数据。无关键词命中只说明该范围和词表的扫描结果；必须结合实际画面、听音和元数据检查，才能给出有边界的结论。

## 最后核对

打开最终 ZIP 的条目并核对版本，确认没有旧导出、私有素材、凭据、绝对用户路径或无关工程。按用户要求提供可播放成片、可编辑源码、必要素材和运行方式；分享 Skill 时仅包含可复用指令、引用与必要脚本，不夹带本次客户项目。
